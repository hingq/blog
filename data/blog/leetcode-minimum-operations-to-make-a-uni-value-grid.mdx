## 题目描述

给你一个大小为 `m x n` 的二维整数网格 `grid` 和一个整数 `x` 。每一次操作，你可以对 `grid` 中的任一元素 **加** `x` 或 **减** `x` 。

**单值网格** 是全部元素都相等的网格。

返回使网格化为单值网格所需的 **最小** 操作数。如果不能，返回 `-1` 。

## 题解分析

### 解题思路

本题的核心是寻找一个目标值，使得网格中所有元素变为该值的操作次数最少。我们可以将问题拆解为以下几个步骤：

#### 1. 判定可行性

每次操作只能对元素加 $x$ 或减 $x$。这意味着，如果两个数 $a$ 和 $b$ 能够通过有限次操作变得相等，那么它们必须满足：
$$(a - b) \mod x = 0 \implies a \equiv b \pmod x$$
即网格中所有元素对 $x$ 取模的余数必须相同。如果存在任何一个元素其余数不同，则无法达成目标，直接返回 `-1`。

#### 2. 转化为经典中位数问题

假设目标值为 $T$，网格中所有元素为 $a_1, a_2, \dots, a_k$（其中 $k = m \times n$）。总操作步数为：
$$S = \sum_{i=1}^k \frac{|a_i - T|}{x} = \frac{1}{x} \sum_{i=1}^k |a_i - T|$$
要使 $S$ 最小，等价于使 $\sum_{i=1}^k |a_i - T|$ 最小。
这是一个经典的数学问题：**给定数轴上的一组点，到所有点距离之和最小的点是这组点的中位数。**

#### 3. 算法流程

1. 将二维网格 `grid` 展平为一维数组 `nums`。
2. 遍历数组，检查是否所有元素 `nums[i] % x` 都相等。若不相等，返回 `-1`。
3. 对数组 `nums` 进行排序。
4. 取排序后的中位数 $T = nums[k // 2]$。
5. 遍历数组计算 $\sum |nums[i] - T| / x$ 并返回结果。

### 复杂度分析

- **时间复杂度**: $O(N \log N)$，其中 $N = m \times n$。主要的开销在于对 $N$ 个元素进行排序。
- **空间复杂度**: $O(N)$，需要一个额外的数组来存储展平后的网格元素。

### 代码实现 (Python)

```python
class Solution:
    def minOperations(self, grid: List[List[int]], x: int) -> int:
        # 1. 展平网格
        nums = []
        for row in grid:
            nums.extend(row)

        # 2. 检查可行性
        # 所有元素相对于 x 的余数必须一致
        mod_val = nums[0] % x
        for val in nums:
            if val % x != mod_val:
                return -1

        # 3. 排序寻找中位数
        nums.sort()
        n = len(nums)
        median = nums[n // 2]

        # 4. 计算最小操作数
        ans = 0
        for val in nums:
            ans += abs(val - median) // x

        return ans
```

### 代码实现 (Rust)

```rust
impl Solution {
    pub fn min_operations(grid: Vec<Vec<i32>>, x: i32) -> i32 {
        let mut nums: Vec<i32> = grid.into_iter().flatten().collect();
        let n = nums.len();

        // 检查可行性：所有数对 x 取模余数必须相同
        let target_mod = nums[0] % x;
        if !nums.iter().all(|&val| val % x == target_mod) {
            return -1;
        }

        // 排序以寻找中位数
        nums.sort_unstable();
        let median = nums[n / 2];

        // 计算到中位数的步数之和
        nums.iter()
            .map(|&val| (val - median).abs() / x)
            .sum()
    }
}
```

### 总结

该问题结合了**数论基础**（余数判别）与**统计学性质**（中位数最小化绝对偏差和）。在实现时，利用排序寻找中位数是最直观的方法；若对性能有极高要求，可以使用 _Quick Select_ 算法将中位数的寻找过程优化至平均 $O(N)$ 时间复杂度。
