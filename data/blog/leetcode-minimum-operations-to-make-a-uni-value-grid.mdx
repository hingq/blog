## 题目描述

给你一个大小为 `m x n` 的二维整数网格 `grid` 和一个整数 `x` 。每一次操作，你可以对 `grid` 中的任一元素 **加** `x` 或 **减** `x` 。

**单值网格** 是全部元素都相等的网格。

返回使网格化为单值网格所需的 **最小** 操作数。如果不能，返回 `-1` 。

## 解题思路

本题的目标是通过加减整数 $x$，使网格中所有元素相等。我们需要解决两个核心问题：
1. **可行性判断**：什么时候无法使所有元素相等？
2. **最优目标值**：如果可行，变成哪个数值能使操作次数最少？

### 1. 可行性判断
两个数 $a$ 和 $b$ 能够通过加减 $x$ 变得相等，当且仅当它们的差值是 $x$ 的倍数，即：
$|a - b| \pmod x = 0$
这意味着网格中的所有元素对 $x$ 取模的结果必须相同。如果存在任何一个元素与首个元素的余数不同，直接返回 $-1$。

### 2. 最优目标值
假设我们将所有元素都变为目标值 $T$。总操作次数为：
$$Cost = \sum_{i,j} \frac{|grid[i][j] - T|}{x} = \frac{1}{x} \sum_{i,j} |grid[i][j] - T|$$
由于 $x$ 是常数，最小化总操作数等价于最小化 $\sum |grid[i][j] - T|$。

这是一个经典的统计学问题：**给定一组数，求一个数 $T$ 使得各数到 $T$ 的绝对距离之和最小**。
结论是：**$T$ 必须是这组数的中位数**。

### 3. 算法步骤
1. 将二维网格 `grid` 展平为一维数组 `nums`。
2. 遍历数组，检查是否所有元素 `nums[i] % x` 都相等。若不相等，返回 $-1$。
3. 对数组进行排序。
4. 取排序后数组的中位数 $T = nums[len/2]$。
5. 计算每个元素与 $T$ 的差的绝对值，除以 $x$ 后累加即为答案。

## 复杂度分析

- **时间复杂度**: $O(N \log N)$，其中 $N = m \times n$。主要开销在于对 $N$ 个元素进行排序。如果使用快速选择算法（QuickSelect）寻找中位数，可以将复杂度优化至 $O(N)$。
- **空间复杂度**: $O(N)$，需要一个一维数组存储网格中的所有元素。

## 代码实现 (Python)

```python
class Solution:
    def minOperations(self, grid: list[list[int]], x: int) -> int:
        # 1. 将二维网格展平
        nums = []
        for row in grid:
            nums.extend(row)

        # 2. 检查可行性
        # 所有元素对 x 的余数必须相同
        mod = nums[0] % x
        for num in nums:
            if num % x != mod:
                return -1

        # 3. 排序找中位数
        nums.sort()
        n = len(nums)
        median = nums[n // 2]

        # 4. 计算总操作数
        ans = 0
        for num in nums:
            # 此时 num - median 一定能被 x 整除
            ans += abs(num - median) // x

        return ans
```

## 代码实现 (Rust)

```rust
impl Solution {
    pub fn min_operations(grid: Vec<Vec<i32>>, x: i32) -> i32 {
        let mut nums: Vec<i32> = grid.into_iter().flatten().collect();
        let n = nums.len();

        // 1. 检查可行性
        let target_mod = nums[0] % x;
        for &num in &nums {
            if num % x != target_mod {
                return -1;
            }
        }

        // 2. 寻找中位数
        // 使用 select_nth_unstable 实现 O(N) 查找中位数
        let mid = n / 2;
        nums.select_nth_unstable(mid);
        let median = nums[mid];

        // 3. 计算结果
        nums.iter()
            .map(|&num| (num - median).abs() / x)
            .sum()
    }
}
```

### 为什么是中位数？
直观理解：假设当前目标值 $T$ 左边有 $n_1$ 个数，右边有 $n_2$ 个数。
- 如果将 $T$ 增大 $d$，左边的数到 $T$ 的距离都会增加 $d$，右边的数距离减少 $d$。总距离变化为 $(n_1 - n_2) \cdot d$。
- 为了让总距离减小，我们应该向数量多的一侧移动 $T$。
- 当 $n_1 = n_2$ 时（即 $T$ 位于中位数），达到平衡点，总距离最小。
