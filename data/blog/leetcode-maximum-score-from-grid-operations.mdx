## 题目描述

给你一个大小为 `n x n` 的二维矩阵 `grid` ，一开始所有格子都是白色的。一次操作中，你可以选择任意下标为 `(i, j)` 的格子，并将第 `j` 列中从最上面到第 `i` 行所有格子改成黑色。

如果格子 `(i, j)` 为白色，且左边或者右边的格子至少一个格子为黑色，那么我们将 `grid[i][j]` 加到最后网格图的总分中去。

请你返回执行任意次操作以后，最终网格图的 **最大** 总分数。

**示例 1：**

<span><b>输出：</b>11</span>

**解释：**

<Image src="https://assets.leetcode.com/uploads/2024/05/11/one.png" alt="Image" />

第一次操作中，我们将第 1 列中，最上面的格子到第 3 行的格子染成黑色。第二次操作中，我们将第 4 列中，最上面的格子到最后一行的格子染成黑色。最后网格图总分为 `grid[3][0] + grid[1][2] + grid[3][3]` 等于 11 。

</div>

**提示：**

- `1 <= n == grid.length <= 100`
- `n == grid[i].length`
- `0 <= grid[i][j] <= 10^9`

## 题解分析

### 解题思路分析

#### 1. 题目建模
*   **状态定义**：每一列 $j$ 涂黑的高度 $h_j \in [0, n]$（表示从第 0 行到第 $h_j-1$ 行涂黑）。
*   **得分条件**：格子 $(i, j)$ 贡献分数的前提是它为白色（$i \ge h_j$），且左邻 $(i, j-1)$ 或右邻 $(i, j+1)$ 至少有一个是黑色。
*   **得分公式**：对于第 $j$ 列，其贡献的总分为 $\text{grid}[h_j \dots \max(h_{j-1}, h_{j+1})-1][j]$。即第 $j$ 列的得分取决于它自身的高度以及左右相邻两列的高度。
*   **总分**：$\sum_{j=0}^{n-1} \max(0, \text{PreSum}(j, \max(h_{j-1}, h_{j+1})) - \text{PreSum}(j, h_j))$，其中 $\text{PreSum}(j, h)$ 表示第 $j$ 列前 $h$ 个元素的和。为了处理边界，可以设 $h_{-1} = 0, h_n = 0$。

#### 2. 动态规划设计
我们需要逐列处理，但在处理第 $j$ 列时，它的得分取决于 $h_{j-1}$ 和 $h_{j+1}$。为了消除这种“未来依赖”，我们可以将得分的计算逻辑挂载在第 $j-1$ 列上。

定义 $dp[j][c][p]$ 为处理完前 $j$ 列后，且第 $j$ 列高度为 $c$，第 $j-1$ 列高度为 $p$ 时的最大总分。
当从 $dp[j-1][p][k]$ 转移到 $dp[j][c][p]$ 时，我们实际上确定了第 $j-1$ 列的左右邻居高度（左邻为 $k$，右邻为 $c$）。
此时，第 $j-1$ 列增加的分数为：
$$\text{Score}(j-1, p, k, c) = \max(0, \text{PreSum}(j-1, \max(k, c)) - \text{PreSum}(j-1, p))$$

#### 3. 状态转移优化
基础转移方程：
$dp[j][c][p] = \max_{0 \le k \le n} \{ dp[j-1][p][k] + \text{Score}(j-1, p, k, c) \}$

直接转移的时间复杂度为 $O(n^4)$，由于 $n=100$，需要优化到 $O(n^3)$。
观察 $\text{Score}$ 的公式，对于固定的 $j, p, c$，我们可以根据 $k$ 与 $c$ 和 $p$ 的关系进行拆解：
*   **若 $c > p$**:
    *   当 $k \le c$ 时：$\max(k, c) = c$，得分 $= \text{PreSum}(j-1, c) - \text{PreSum}(j-1, p)$。
    *   当 $k > c$ 时：$\max(k, c) = k$，得分 $= \text{PreSum}(j-1, k) - \text{PreSum}(j-1, p)$（因为 $k > c > p$）。
*   **若 $c \le p$**:
    *   当 $k \le p$ 时：$\max(k, c) \le p$，得分 $= 0$。
    *   当 $k > p$ 时：$\max(k, c) = k$，得分 $= \text{PreSum}(j-1, k) - \text{PreSum}(j-1, p)$。

通过维护 $dp[j-1][p][k]$ 的**前缀最大值**和 $dp[j-1][p][k] + \text{PreSum}(j-1, k)$ 的**后缀最大值**，可以在 $O(1)$ 时间内完成上述转移。

### 复杂度分析
*   **时间复杂度**：$O(n^3)$。共有 $n$ 列，每列有 $n^2$ 个状态，每个状态通过预处理后的 $O(1)$ 转移。
*   **空间复杂度**：$O(n^2)$。使用滚动数组优化，仅需保存两列的状态空间。

### 代码实现 (Python)

```python
class Solution:
    def maximumScore(self, grid: List[List[int]]) -> int:
        n = len(grid)
        # 预计算每一列的前缀和
        ps = [[0] * (n + 1) for _ in range(n)]
        for j in range(n):
            for i in range(n):
                ps[j][i + 1] = ps[j][i] + grid[i][j]

        # dp[c][p] 表示当前列高度为 c，前一列高度为 p 时的最大分数
        # 初始化：对于第0列，前一列(假想的第-1列)高度为0
        dp = [[-1] * (n + 1) for _ in range(n + 1)]
        for c in range(n + 1):
            dp[c][0] = 0

        # 预分配辅助数组以优化速度
        pref_dp = [-1] * (n + 1)
        suff_dp_ps = [-1] * (n + 2)

        # 遍历每一列，j表示当前正在考虑的列，计算 j-1 列的贡献
        for j in range(1, n + 1):
            new_dp = [[-1] * (n + 1) for _ in range(n + 1)]
            ps_idx = j - 1 # 当前计算贡献的列索引
            curr_ps = ps[ps_idx]

            for p in range(n + 1):
                # p 是第 j-1 列的高度，我们需要通过 k (j-2列高度) 进行转移
                row_prev = dp[p]

                # 预计算前缀最大 dp[p][k]
                curr_max = -1
                for k in range(n + 1):
                    if row_prev[k] > curr_max: curr_max = row_prev[k]
                    pref_dp[k] = curr_max

                # 预计算后缀最大 dp[p][k] + PreSum(j-1, k)
                curr_max = -1
                for k in range(n, -1, -1):
                    if row_prev[k] != -1:
                        val = row_prev[k] + curr_ps[k]
                        if val > curr_max: curr_max = val
                    suff_dp_ps[k] = curr_max

                ps_p = curr_ps[p]

                # 优化：当 c <= p 时，结果与 c 无关，统一计算
                val_le_p = -1
                if pref_dp[p] != -1:
                    val_le_p = pref_dp[p]
                if suff_dp_ps[p + 1] != -1:
                    tmp = suff_dp_ps[p + 1] - ps_p
                    if tmp > val_le_p: val_le_p = tmp

                for c in range(n + 1):
                    if c <= p:
                        new_dp[c][p] = val_le_p
                    else:
                        # c > p 分支
                        res = -1
                        # Case k <= c: max(k, c) = c
                        if pref_dp[c] != -1:
                            res = pref_dp[c] + curr_ps[c] - ps_p
                        # Case k > c: max(k, c) = k
                        if suff_dp_ps[c + 1] != -1:
                            tmp = suff_dp_ps[c + 1] - ps_p
                            if tmp > res: res = tmp
                        new_dp[c][p] = res
            dp = new_dp

        # 最终第 n 列是假想的，其高度 c 必须为 0
        return max(dp[0])

```
