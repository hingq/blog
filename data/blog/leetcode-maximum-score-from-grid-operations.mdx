## 题目描述

给你一个大小为 `n x n` 的二维矩阵 `grid` ，一开始所有格子都是白色的。一次操作中，你可以选择任意下标为 `(i, j)` 的格子，并将第 `j` 列中从最上面到第 `i` 行所有格子改成黑色。

如果格子 `(i, j)` 为白色，且左边或者右边的格子至少一个格子为黑色，那么我们将 `grid[i][j]` 加到最后网格图的总分中去。

请你返回执行任意次操作以后，最终网格图的 **最大** 总分数。

<span><b>输出：</b>11</span>

## 题解分析

这是一个经典的网格图动态规划问题。由于 $n$ 的规模较小 ($n \le 100$)，我们可以考虑一个复杂度在 $O(n^3)$ 到 $O(n^4)$ 之间的动态规划方案。

### 解题思路分析

**1. 题目建模**
每个列 $j$ 可以选择一个高度 $h_j \in [0, n]$，将该列的前 $h_j$ 个格子染成黑色。
一个格子 $(i, j)$ 能得分的条件是：
- 该格子是白色的：即 $i \ge h_j$。
- 其左邻居或右邻居至少有一个是黑色的：即 $i < h_{j-1}$ 或 $i < h_{j+1}$。

因此，第 $j$ 列的得分总和为：
$$\sum_{i=h_j}^{\max(h_{j-1}, h_{j+1}) - 1} \text{grid}[i][j]$$
注意：如果 $h_j \ge \max(h_{j-1}, h_{j+1})$，则该列得分为 0。

**2. 动态规划状态设计**
我们需要逐列决定高度。观察发现，第 $j$ 列的得分取决于 $h_{j-1}, h_j, h_{j+1}$。为了在处理第 $j$ 列时计算其得分，我们需要知道前一列的高度和当前列的高度，并预留对后一列高度的影响。

定义 $dp[i][curr][prev]$ 为：处理完前 $i$ 列，且第 $i$ 列高度为 $curr$，第 $i-1$ 列高度为 $prev$ 时能获得的最大分数。
此时，我们已经可以确定的分数包括：
- 前 $i-1$ 列的所有得分。
- 第 $i$ 列由其左邻居 $h_{i-1}$ 贡献的得分。

当我们从第 $i$ 列转移到 $i+1$ 列，并选择第 $i+1$ 列的高度为 $next$ 时，会增加：
- 第 $i+1$ 列由于左邻居 $h_i$ 产生的得分。
- 第 $i$ 列由于右邻居 $h_{i+1}$ 产生、且之前未被左邻居 $h_{i-1}$ 覆盖的额外得分。

**3. 转移方程与优化**
设 $S(col, row, target\_h)$ 为第 $col$ 列中，从行 $row$ 到 $target\_h-1$ 的元素和。
$$dp[i+1][next][curr] = \max_{prev} \{ dp[i][curr][prev] + S(i+1, next, curr) + \max(0, S(i, curr, next) - S(i, curr, prev)) \}$$

直接计算是 $O(n^4)$。我们可以观察到，对于固定的 $curr$ 和 $next$，$\max$ 内部只有 $S(i, curr, next) - S(i, curr, prev)$ 这一项与 $prev$ 相关。
利用 $S$ 函数的单调性，我们可以通过维护前缀和后缀最大值，将转移优化到 $O(1)$，从而总复杂度降为 $O(n^3)$。

### 复杂度分析
- **时间复杂度**: $O(n^3)$。我们需要遍历 $n$ 列，每列遍历当前高度和前一高度（$n^2$），内部优化后转移为 $O(1)$。
- **空间复杂度**: $O(n^2)$。只需要存储当前列和前一列的 DP 状态。

### 代码实现 (Python)

```python
class Solution:
    def maxScore(self, grid: List[List[int]]) -> int:
        n = len(grid)
        # 预计算每一列的前缀和，方便快速求出 S(col, row, target_h)
        pref = [[0] * n for _ in range(n + 1)]
        for j in range(n):
            for i in range(n):
                pref[i + 1][j] = pref[i][j] + grid[i][j]

        # 计算列 col 在高度为 row 时，受邻居高度 target_h 影响获得的得分
        def get_S(col, row, target_h):
            if col < 0 or col >= n or target_h <= row:
                return 0
            return pref[target_h][col] - pref[row][col]

        # dp[curr_h][prev_h] 表示当前列高度为 curr_h，前一列高度为 prev_h 时的最大分数
        dp = [[0] * (n + 1) for _ in range(n + 1)]

        # 遍历每一列，多走一列（到 n）是为了结算最后一列受右侧（高度0）影响后的得分
        for i in range(n + 1):
            new_dp = [[0] * (n + 1) for _ in range(n + 1)]
            for curr in range(n + 1):
                # 优化 O(n^4) 到 O(n^3)
                # 我们需要计算 max_prev (dp[curr][prev] + max(0, S(i-1, curr, next) - S(i-1, curr, prev)))

                # 预计算两部分：
                # 1. 当 S(i-1, curr, prev) >= S(i-1, curr, next) 时，取 dp[curr][prev] 的最大值
                # 2. 当 S(i-1, curr, prev) < S(i-1, curr, next) 时，取 dp[curr][prev] - S(i-1, curr, prev) 的最大值

                # 针对固定 curr，计算所有可能 prev 的辅助数组
                f_p = dp[curr]
                g_p = [get_S(i - 1, curr, p) for p in range(n + 1)]

                # res_a[v] = max_{p >= v} f(p)
                res_a = [0] * (n + 1)
                cur_max_a = -1
                for p in range(n, -1, -1):
                    cur_max_a = max(cur_max_a, f_p[p])
                    res_a[p] = cur_max_a

                # res_b[v] = max_{p < v} (f(p) - g(p))
                res_b = [0] * (n + 1)
                cur_max_b = -float('inf')
                for p in range(n + 1):
                    res_b[p] = cur_max_b
                    cur_max_b = max(cur_max_b, f_p[p] - g_p[p])

                for next_h in range(n + 1):
                    g_v = get_S(i - 1, curr, next_h)
                    # 状态转移
                    term = max(res_a[next_h], g_v + res_b[next_h])
                    new_dp[next_h][curr] = get_S(i, next_h, curr) + term
            dp = new_dp

        # 最终结果是在处理完所有列后，虚拟的第 n 列高度为 0 时的最大值
        return max(dp[0])

```

### 解题要点
1. **虚拟边界**：通过引入第 $n$ 列且高度固定为 0，可以统一处理最后一列的得分逻辑。
2. **贡献拆分**：将每一列的得分拆分为“左侧贡献”和“右侧额外贡献”，避免了复杂的 $\max(h_{j-1}, h_{j+1})$ 讨论。
3. **单调性优化**：利用高度增加则得分增加的单调性，将内层循环从 $O(n^2)$ 优化至 $O(n)$。
